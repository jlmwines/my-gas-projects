# Marketing Folder

Campaigns, promotions, and customer communications for JLM Wines.

## Folder Layout

- `marketing/plans/` — active plans (intent, not yet fully built): `FLYER_PLAN.md`, `REWARDS_PLAN.md`. `_archive/` holds graduated or deferred plans (e.g. `WHATSAPP_TRANSITION.md` — account is live and in use, but the broader build has no near-term plan; `META_ADS_PLAN.md` — Meta test concluded 2026-08-31).
- `marketing/_resources/` — session references consulted while doing marketing work, not plans or manager-facing docs: `EMAIL_GUIDELINES.md` (design decisions, Mailchimp process, Hebrew checklist — read before building any promo/companion email HTML), `NEWSLETTER_REFERENCE.md` (full monthly-issue workflow: layout, Making Wine series, Drive template/docx delivery, issue cadence — read before building an issue), `PAID_ADS_REFERENCE.md` (outcome and reusable lessons from the Meta/Google paid-ads tests — read before any future paid round). Reference HTML: `content/newsletter/2026-06/2026-06-handling-en.html` + HE sibling.
- Newsletter + email files live in `content/newsletter/<YYYY-MM>/`, shared assets (banner, QR codes) in `content/newsletter/images/`.
- `marketing/flyer/` — flyer print artifacts.

## Related Folders

- `business/` — Strategy docs including `CONTENT_STRATEGY.md`
- `content/` — Blog posts, guides, educational content
- `website/` — Frontend/website code

## Brand Voice Quick Reference

All marketing must reflect:

- **Friendly, personal, never talks down**
- **Anti-snob** — wine without pretension
- **Customer:** People who drink wine (not "wine lovers"), want convenience and consistency
- **Owner's tone:** Polite, earnest, upbeat, service-dedicated, never negative about competitors

Full guidelines: `business/CONTENT_STRATEGY.md`
